# Strontium titanate

Strontium titanate (SrTiO3, cubic perovskite, a = 3.905 A). Three species with distinct coordinations: Sr is 12-coordinated by O, Ti is 6-coordinated by O (octahedral), and each O has 2 Ti + 4 Sr neighbours.

## Reference crystal

```python
from ase.io import read
atoms = read('SrTiO3.cif')  # perovskite structure
```
